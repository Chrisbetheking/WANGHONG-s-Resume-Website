Personal full-stack project with a front-end workspace, RAG retrieval, AI tools, logs, and evaluation.

Background: study-abroad consulting workflows are scattered across student profiles, school recommendations, writing plans, documents, and follow-ups. EduAgent turns them into one usable workspace.

StackReact + TypeScript, NestJS, DeepSeek, Embedding, Supabase / pgvector, Netlify, Render

Front-end work

  • Built pages for AI chat, leads, application plans, knowledge base, plan engine, RAG evaluation, and system logs.
  • Implemented complex forms, collapsible panels, local cache, state management, mobile layout, and Error Boundary.
  • Added long-running AI request hints, loading / empty / error states, graceful failure handling, and Markdown / JSON export.
  • Displayed RAG source, score, retrievalMode, cacheHit, requestId, and tool path as readable UI.

AI / engineering work
