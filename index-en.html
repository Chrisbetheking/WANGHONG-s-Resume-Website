Healthcare Information Retrieval Demo

A small health-question prototype for text processing and information retrieval practice

The project was adjusted from a symptom Q&A prototype into an information retrieval demo to avoid diagnosis, prescription, or treatment-advice wording that is not suitable for a public demo. The current version extracts keywords from user input and returns related health information, matching evidence, and risk reminders.

Implementation

  • Designed the input form, task switching, result cards, and risk reminder area.
  • Implemented basic text cleaning, keyword extraction, and symptom-term matching.
  • Replaced high-risk wording with health information matching and care-seeking reminders.

Technical focus

  • Basic NLP workflow, keyword matching, and structured result display.
  • Reached around 80% keyword-matching accuracy on a self-built test sample set.
  • The page clearly states that the demo cannot replace a doctor’s diagnosis.
