Project 02

Healthcare Information Retrieval Demo

Symptom description input, keyword matching, health information retrieval and risk-signal reminders

Live Demo
Python JavaScript Basic NLP Keyword Matching Safety Notice

Developed a healthcare information retrieval demo with Python and JavaScript. The system supports symptom description input, keyword extraction, health knowledge matching and risk-signal reminders. The output is positioned as information retrieval rather than medical diagnosis.

  • Problem: User symptom descriptions are often informal and unstructured, so the system needs to extract useful health-related keywords from free text.
  • Text processing: Used text cleaning, keyword extraction and symptom normalization to convert user descriptions into matchable information.
  • Matching logic: Combined keyword matching with a local health knowledge base to present related health information.
  • Safety boundary: Reframed “disease probability / treatment advice” into “health information match / medical attention reminder” to avoid diagnosis-like output.
  • Result: In self-built symptom test cases, keyword matching accuracy reached about 80%.
