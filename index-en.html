Healthcare Information Retrieval Demo

A small health-question prototype for practicing text processing and information retrieval

This project started as a symptom Q&A idea. Later, I realized that medical projects should not casually claim diagnosis or treatment advice, so I adjusted it into an information retrieval demo. It now works more like a health information lookup tool: it extracts keywords from user input and returns related health information, matching evidence, and risk reminders.

What I worked on

  • Designed the input form, task switching, result cards, and risk reminder area.
  • Implemented basic text cleaning, keyword extraction, and symptom-term matching.
  • Replaced misleading “diagnosis / treatment advice” wording with “health information matching / seek medical attention reminders”.

Result

  • The demo returns structured information based on symptom descriptions instead of only showing plain text.
  • On my own small test set, keyword matching accuracy was around 80%.
  • The page clearly states that it cannot replace a doctor’s diagnosis.
