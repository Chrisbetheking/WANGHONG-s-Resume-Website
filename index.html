Project 02
Java Java Swing OOP CSV 成绩计算

Java 学生成绩管理系统

Java 桌面端系统，并额外整理了成绩计算 Web Demo

一个基于 Java 的学生成绩管理系统，覆盖用户登录、学生信息管理、成绩录入、 总评计算、补考名单筛选和报告导出。为了降低查看成本，核心成绩计算逻辑被单独整理为网页 Demo。

实现内容

  • 设计学生、课程、成绩、用户等基础对象和模块边界。
  • 实现登录认证、成绩统计、补考筛选、总评计算和报告导出。
  • 处理异常输入和边界情况，提高成绩计算过程的稳定性。

技术重点

  • 基于 Java OOP 拆分数据对象、业务逻辑和界面交互。
  • 使用 CSV 进行基础数据读写和测试数据管理。
  • 基于自建测试数据集校验后，成绩计算准确率约 95%。

APU 智能校园交通系统

技术重点

  • 动画控制、倒计时状态和界面状态变化展示。
  • 面向真实校园场景的移动端交互流程设计。

技术重点

  • 基础 NLP 思路、关键词匹配和结构化结果展示。
