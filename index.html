Project 02

医疗健康信息检索 Demo

症状描述输入、关键词匹配、健康知识检索与风险信号提示
Python JavaScript NLP 基础 关键词匹配 安全提示

面向健康问答场景的前端信息检索原型，支持症状描述匹配、健康知识查询和风险信号提示。这个项目的重点是信息检索和安全边界，不把输出包装成医疗诊断。

  • 通过文本清洗、关键词提取和症状归一化，将自由输入转换为可匹配的信息。
  • 结合本地健康知识库进行关键词匹配，输出结构化健康信息、匹配依据和风险提示。
  • 将“疾病概率 / 治疗建议”降级为“健康信息匹配度 / 就医提醒”，避免诊断式表达。
