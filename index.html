AI 智能医疗问答系统

基于 Python 的症状识别、疾病匹配与多轮问答系统
Colab 演示
Python NLP 文本清洗 相似度计算 规则匹配 多轮问答

基于 Python 开发的 AI 医疗问答系统，支持用户输入症状描述后进行疾病推荐、初步诊断与治疗建议展示。

  • 问题背景：用户输入的症状描述通常较为口语化、非结构化，系统需要从自由文本中提取有效症状信息。
  • 文本处理：通过文本清洗、关键词提取、症状归一化等方式，将用户描述转换为可匹配的结构化信息。
  • 匹配算法：结合相似度计算与规则匹配，对症状与疾病进行关联分析，提高系统对用户症状的识别准确性。
  • 多轮问答：支持用户在自由描述与结构化问答之间切换，通过补充问题完善症状信息，减少信息缺失带来的误判。
  • 结果输出：系统输出疾病概率、治疗建议与注意事项，匹配准确率达到 80%。
可讲重点：NLP 文本处理、多轮问答设计、症状匹配算法、结果结构化展示。
