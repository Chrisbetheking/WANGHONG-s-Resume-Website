EduAgent｜AI + RAG 留学咨询工作台

个人全栈项目：用前端工作台承载 AI 咨询、申请案卷、知识库检索、日志和评测闭环

背景：留学咨询里，学生背景、选校、文书、材料清单和销售跟进分散在不同工具里。EduAgent 把这些流程放进一个工作台，顾问输入学生信息后，可以得到结构化建议、文书方向、跟进话术和材料清单。

技术栈React + TypeScript、NestJS、DeepSeek、SiliconFlow / Qwen Embedding、Supabase / pgvector、Netlify、Render
前端架构业务路由拆分、API 封装、表单状态、Loading / Empty / Error、复制导出、Error Boundary
AI / RAG文档切片、向量化存储、Top-K 召回、关键词 + 向量混合检索、来源引用、SSE 流式输出
质量闭环8 个标准 RAG 评测问题，Hit@1、Hit@3、MRR、P95、缓存命中、异常样本

前端职责

  • 使用 React + TypeScript 搭建 AI 咨询、客户线索、申请案卷、知识库、方案引擎、检索评测和系统日志等页面。
  • 实现复杂表单、折叠面板、目录跳转、本地缓存、状态管理、移动端适配和 Error Boundary。
  • 在 Chat、文书生成和评测页补齐长耗时提示、Loading / Empty / Error 状态、异常兜底和结果复制 / Markdown / JSON 导出。
  • 将 RAG 来源、score、retrievalMode、cacheHit、requestId、工具调用路径等字段转成可读 UI，方便定位问题。

AI / 工程亮点

  • 接入 DeepSeek 与 Embedding 服务，实现文档切片、向量化存储、Top-K 召回、来源引用和检索评测。
  • 设计 weighted-fit 选校评分逻辑，将 GPA、专业匹配、语言成绩、项目经历和预算转为可解释分数，用于冲刺 / 匹配 / 保底分层。
  • 后端封装 JWT、访客额度、SSE、DTO 校验、限流、日志和 Markdown / JSON 导出，避免前端直接暴露模型 Key。
  • 用 Netlify 承载前端入口、Render 承载后端，并为海外后端冷启动和长 AI 请求设计等待提示与备用结果。
可面试点多页面前端架构、复杂表单状态、AI 流式渲染、接口封装、错误边界。
检索算法感Top-K、混合检索、评分逻辑、RAG 评测指标和 bad case 复盘。
线上结果项目已部署，支持 Demo 体验、源码查看、日志追踪和 PDF 导出。
实现边界：Demo 中的选校、文书和材料建议用于展示工程流程，真实申请仍需人工核对官网、截止日期、语言小分和预算。

TokenFence Studio｜本地优先 AI 安全与多模型编排工作台

开源项目：把 Prompt 发送前的安全检查、脱敏、意图判断、上下文压缩和模型路由做成一个可运行的工作台

这个项目不是普通 Chat UI，而是站在模型调用前面做一层“预处理”：先看内容是否有风险、是否需要脱敏、是否应该压缩、该走云端模型还是本地模型，再把最终 Prompt 和路由结果展示出来。

技术栈Next.js 14、React、TypeScript、Tailwind CSS、Zod、Commander、tsx、MCP SDK
安全层本地扫描 API Key、邮箱、手机号、数据库 URL、Access Token、Secret 赋值和中文身份信息等风险内容
模型编排Provider Registry、多模型对比、文件级模型路由、risk status、token usage 和 latency 展示
工具入口Web Studio、CLI 命令、本地归档、Provider 设置、Agent Context Pack 和 MCP Server 原型

前端 / 产品表达

  • 搭建 Chat Workspace、Provider Management、Prompt Guard、Model Matrix、Local Archive 等模块，让功能不只是写在 README，而是可以点开体验。
  • 把风险等级、脱敏结果、策略模式、模型选择、文件路由和运行记录做成可读 UI，降低 AI 工具的黑盒感。
  • 按“Strict / Balanced / Fast / Developer”组织策略，让不同场景能切换安全与效率的取舍。

工程 / AI 工具链

  • 抽象 scanner、redactor、risk engine、compressor、intent engine、provider adapters 等模块，便于后续扩展检测规则和模型供应商。
  • 支持 OpenAI-compatible、国内模型、本地 Ollama / LM Studio 等 Provider，避免把项目绑定到单一模型。
  • 补充 CLI 和 MCP Server 原型，为 Claude Code、Codex、MCP Agent 等工作流准备更干净的上下文包。
可面试点为什么 AI 应用需要 Prompt 发送前的安全层，而不只是调用模型接口。
工程抽象Scanner / Redactor / Router / Provider Registry 的边界怎么划分。
后续方向Search Grounding、Judge Model、Provider Fallback、VS Code Extension、Local Vector Search。
