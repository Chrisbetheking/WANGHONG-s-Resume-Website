医疗健康信息检索 Demo

症状描述输入、关键词匹配、健康知识检索与风险信号提示

在线演示
Python JavaScript NLP 基础 关键词匹配 安全提示

基于 Python / JavaScript 开发医疗健康信息检索 Demo，支持症状描述输入、关键词提取、健康知识匹配与风险信号提示；通过结构化结果展示和安全免责声明设计，模拟健康问答场景下的信息检索流程。

  • 问题背景：用户输入的症状描述通常较为口语化、非结构化，系统需要从自由文本中提取有效健康关键词。
  • 文本处理：通过文本清洗、关键词提取和症状归一化等方式，将用户描述转换为可匹配的结构化信息。
  • 匹配逻辑：结合关键词匹配与本地健康知识库，对症状与相关健康信息进行关联展示。
  • 安全边界：将“疾病概率 / 治疗建议”降级为“健康信息匹配度 / 就医建议提醒”，避免输出诊断或处方性质内容。
  • 结果口径：在自建症状测试样例中，关键词匹配准确率约 80%。
