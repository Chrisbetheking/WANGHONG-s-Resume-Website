Project 01
AI Agent LLM 应用 Prompt 业务流程 前端交互

企业级 AI 智能体工作流系统

实习期间参与的内部 AI 提效工具

这个项目来自真实教育咨询业务。公司内部版本涉及业务数据和具体规则，所以不能直接公开源码。我另外整理了一个脱敏 Demo，用留学申请场景来展示类似的工作流：填写条件、生成推荐、换算 GPA、输出申请文案。

我做了什么

  • 参与把销售、运营、文书老师的高频问题整理成统一的查询和生成流程。
  • 参与前端交互，包括动态表单、任务切换、结构化结果展示、快捷复制和历史记录。
  • 参与 Prompt 流程、查询逻辑、多平台入口接入和上线前测试。

结果

  • 把原本分散在多个工具里的查询、推荐、换算和内容生成集中到一个工作流里。
  • 根据典型任务耗时对比，销售查询效率提升约 60%，累计节省人工查询时间 200+ 小时。
  • 公开 Demo 去掉了公司内部数据，只保留工作流和交互方式。

Project 02
Python JavaScript 关键词匹配 信息检索 安全边界

医疗健康信息检索 Demo

一个用来练习文本处理和信息检索的小型健康问答原型

这个项目一开始是想做“症状问答”，后面我意识到医疗类项目不能随便写诊断和治疗建议，所以把它调整成了信息检索 Demo。现在它更像一个健康知识查询工具：根据用户输入提取关键词，再返回相关健康信息、匹配依据和风险提醒。

我做了什么

  • 设计输入表单、任务切换、结果卡片和风险提示区域。
  • 做了基础文本清洗、关键词提取和症状词匹配。
  • 把原本容易误导的“诊断 / 治疗建议”改成“健康信息匹配 / 就医提醒”。

结果

  • 可以根据症状描述返回结构化信息，而不是只输出一段文字。
  • 在我自己整理的测试样例里，关键词匹配准确率约 80%。
  • 页面里明确提示：这个 Demo 不能替代医生诊断。

Project 03
Flutter Dart CustomPaint Animation 校园场景

APU 智能校园交通系统

围绕校园出行和停车场景做的 Flutter 项目

这个项目主要是练习 Flutter 里比较复杂的界面和状态展示。我把校园交通拆成了几个常见场景：校车路线、车位预约、实时状态、ETA 倒计时和不同角色入口。

我做了什么

  • 设计停车预约、校车状态、路线展示、ETA 倒计时等核心流程。
  • 用 CustomPaint 绘制校园路网，用 AnimationController 模拟公交移动。
  • 把页面拆成多个组件，方便后面继续扩展。

结果

  • 完成了可交互的校园交通 Demo，而不是只停留在静态 UI。
  • 练习了 Flutter 动画、状态展示和响应式布局。
  • 项目结构比一开始更清晰，后续可以继续接真实地图或后端接口。
