Project 01
React TypeScript NestJS Supabase UI/UX RAG Agent

EduAgent｜AI + RAG 留学咨询工作台

个人全栈项目，覆盖前端工作台、后端接口、RAG 检索和工具链编排

这是我目前重点维护的项目。它不是只调模型接口的聊天页面，而是一个可以操作的业务工作台：前端负责多页面表单、结果折叠、导出和移动端适配；后端负责鉴权、AI 调用、知识库、日志和规则算法。顾问输入学生背景后，系统先做适配评分，再生成选校分层、文书方向、销售跟进内容和材料清单。

前端工作台 React/TypeScript、多页面路由、表单状态、折叠结果和响应式布局
后端服务 NestJS 接口、JWT 鉴权、访客额度、错误 fallback
数据链路 Supabase/PostgreSQL 保存会话、文档、切片和日志
RAG & Agent 知识库检索、工具编排、结构化生成和导出
工程观测 记录模型、耗时、RAG 命中、工具链和失败原因

前端与交互实现

  • 使用 React + TypeScript 搭建多页面工作台，覆盖 AI 咨询、客户线索、申请案卷、知识库、方案引擎和系统日志。
  • 实现复杂表单、下拉配置、结果折叠、目录跳转、复制、导出、访客入口和移动端适配，降低演示和实际操作成本。
  • 在前端加入状态缓存和错误边界，切换页面后保留生成结果，并避免单个模块异常导致整页白屏。
  • 持续调整信息架构和卡片布局，让 RAG 来源、工具调用、评分结果和文书内容能被清楚阅读。

后端、算法与产出

  • 设计知识库导入与切片流程，将 documents / chunks 写入 Supabase，并在咨询和工具链中作为检索上下文。
  • 封装 DeepSeek 调用、超时处理、fallback 和调用日志，避免前端直接暴露模型 Key。
  • 实现 weighted-fit 适配评分算法，把 GPA、专业匹配、项目经历、语言和预算转成可解释的选校建议。
  • 在线 Demo 支持管理员登录和访客体验，可跑通 AI 咨询、客户线索、申请案卷、方案引擎、知识库和日志观测。
前端可讲点 复杂表单、页面状态、结果折叠、目录跳转、移动端、导出体验。
后端可讲点 鉴权、限额、服务封装、数据库建模、日志、失败兜底。
AI 可讲点 RAG、Prompt、工具链、规则算法和可观测性结合。
实现边界： Demo 中的院校和申请建议用于展示系统流程，不替代学校官网要求；真实申请仍需人工核对官网、预算、语言小分和截止日期。这个项目的重点是工程链路和业务抽象，而不是“模型直接给最终答案”。

Project 02
Java Java Swing OOP CSV 成绩计算

Java 学生成绩管理系统

Java 桌面端系统，并把核心规则抽成可在线验证的 Web Demo

一个基于 Java 的学生成绩管理系统，覆盖用户登录、学生信息管理、成绩录入、总评计算、补考名单筛选和报告导出。为了让评审不用安装桌面程序，我把核心成绩规则抽出来做成 Web Demo，可以直接输入分数验证计算结果。

实现内容

  • 设计学生、课程、成绩、用户等基础对象和模块边界，按业务流程拆分录入、计算、筛选和导出。
  • 实现登录认证、成绩统计、补考筛选、总评计算、报告导出和异常输入处理。
  • 整理 Web Demo 版本，把核心规则迁移成浏览器可验证的交互页面。

技术重点

  • 基于 Java OOP 拆分数据对象、业务逻辑和界面交互，避免计算逻辑直接写在页面事件里。
  • 使用 CSV 进行基础数据读写、导入导出和测试数据管理。
  • 用自建测试数据覆盖边界分数、缺失分数和补考判断，校验成绩计算规则的稳定性。

Project 03
Flutter Dart Material 3 OpenStreetMap Local State

Flutter 校园交通移动端原型

包含学生端、司机端和管理员端的移动端流程原型

项目围绕校园出行场景设计，包含校车路线浏览、OpenStreetMap 路线回放、停车位预约、乘客签到和预约状态管理，重点练习移动端信息架构、角色切换和状态同步。 公开版本使用本地示例数据和基于真实地点坐标的路线回放，不接入真实 GPS、真实后端或 APU 官方交通数据。

实现内容

  • 设计学生端、司机端和管理员端三角色入口，按角色拆分首页、路线、预约、签到和管理视图。
  • 实现校车预约、停车位选择、预约取消、乘客签到和完成状态等本地流程，并在不同角色页面复用同一份状态。
  • 接入 OpenStreetMap 展示路线，并使用本地路线点位和平均车速模拟路线回放。

技术重点

  • 使用 Flutter、Dart 和 Material 3 搭建移动端界面、页面导航、统一组件和响应式布局。
  • 通过共享本地状态让学生预约后，司机端和管理端能同步看到对应记录，模拟真实业务的状态流转。
  • 整理在线 Demo、GitHub Pages 部署和项目边界说明，方便快速查看。
说明： 该项目是作品集 Demo。地图轨迹为本地路线回放，不是真实 GPS 追踪；数据来自本地示例，不代表官方校园交通系统。

医疗健康信息检索 Demo

文本检索与安全边界练习项目

技术重点

  • 基础 NLP 思路、关键词匹配、规则过滤和结构化结果展示。
